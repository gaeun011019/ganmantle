# 간맨틀 순위 비교 사전

`words.txt`는 **hunspell-dict-ko 0.7.94**에서 추출한 49,485개 표제어로, 단어 유사도 순위를 매기는 고정 비교 집합의 원본입니다. 정답 후보 90개와 모델 파일은 별도로 관리합니다.

## 현재 입력 처리

fastText 경로에서는 앞뒤 공백 제거와 NFC 정규화 후 **완성형 한글 1~40자**를 검사합니다. 정규화 후 남은 낱자 자모·영문·숫자·이모지·내부 공백·구두점·제어 문자는 거절합니다.

비교 사전에 없는 표기나 활용형·새 이름도 실제 fastText 단어 또는 문자 조각 벡터를 만들 수 있으면 점수를 계산합니다. 이를 미등록 단어(OOV) 처리라고 합니다. 목록에 없는 한글 조합도 벡터가 생길 수 있으므로, 형식 검사와 점수 계산이 한국어 단어의 존재·뜻을 보증하지는 않습니다.

짧은 미등록 입력은 사용할 학습 단어나 문자 조각이 없어 0벡터가 나올 수 있습니다. 이때는 다른 한국어 단어를 안내하고 점수·순위·시도 횟수를 만들지 않습니다. 형식 검사는 [words.py](../words.py), 실제 벡터와 오류 처리는 [similarity.py](../similarity.py)가 담당합니다.

## 실제 순위 비교 집합

`scripts/prepare_word_ranks.py`가 원본 표제어를 현재 모델로 계산합니다. **실제 벡터가 없는 단어만 제외**하고 다른 계산 오류는 준비를 중단합니다. 정답 후보는 모두 비교 집합에 들어 있어야 합니다.

- `models/fasttext-ko/word-ranks/words.json`: 유효한 비교 단어.
- `models/fasttext-ko/word-ranks/vectors.npy`: 해당 단어의 정규화된 300차원 실제 벡터.
- `models/fasttext-ko/word-ranks/manifest.json`: 원본 사전 SHA-256·모델 지문·파일 검증 정보와 `excluded_words` 목록.

유효 단어와 제외 단어는 중복 없이 원본 49,485개 전체를 구성해야 합니다. 순위의 실제 비교 단어 수는 이 모델별 결과에 따라 정해집니다. 현재는 제외 목록을 담는 format 2를 사용합니다. 사용하지 않는 MiniLM format 1 호환 경로는 제거했으며 이전 자료는 현재 fastText 모델로 다시 준비해야 합니다.

사전 안팎 입력 모두 이 고정 비교 집합의 실제 코사인 점수와 비교합니다. 정답은 별도 0위, 같은 원 점수는 공동 순위이며 1,000위까지 표시합니다. 1·10·1,000번째 기준 점수도 같은 집합에서 구합니다. 입력이 추가돼도 비교 집합 자체는 늘어나지 않습니다.

텍스트 사전·원본·라이선스는 소스와 함께 Git/Docker에 포함하고, 큰 모델·순위 벡터와 실제 DB는 별도로 보관합니다. 실행 중 외부 사전 API를 사용하지 않습니다. 사전 변경 시 출처·라이선스·정답 후보 호환성을 확인하고 모델별 순위 자료도 다시 준비합니다. 이번 변경과 실제 검사 결과는 [013 변경 기록](../../../CHANGELOG/2026-09/19-013-fasttext-game.md)에서 확인합니다.
