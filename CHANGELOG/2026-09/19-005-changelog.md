## 어떤 내용을 추가했나요?

실제 작업 코드와 설정은 변경하지 않았습니다. 문서 연결 구조를 다음처럼 추가했습니다.

```text
앱 README → CHANGELOG/README.md → 2026-09/README.md → 기능별 기록
                                  TEMPLATE.md → 다음 변경 기록 작성
AGENTS.md → 이후 작업에서 변경 기록과 목록을 함께 갱신
```

기존 구현의 코드는 001~004에 일부 발췌했습니다. 과거의 전체 diff를 만들어 내지 않았고, 기존 검사 결과를 이번에 재실행한 것처럼 기록하지 않았습니다.

## 영향과 남은 일

실행 중인 앱, DB, 실제 `.env`에는 변경이 없습니다. 새 서비스·의존성·자동 감시 프로그램을 추가하지 않았습니다. 사람이 직접 수정한 작업은 템플릿으로 기록해야 합니다. 향후 Git을 사용하면 실제 커밋 번호와 전체 diff를 연결할 수 있습니다.
