## 무엇이 추가되었나요?

한국어를 지원하는 multilingual-e5-small의 ONNX int8 모델로 입력과 정답의 벡터를 계산합니다. 정답 후보에 없는 단어도 서브워드로 처리합니다. 모델 파일이 없거나 검증에 실패하면 점수를 만들지 않고 오류를 반환합니다.

## 핵심 코드

`similarity.py` → `score()`의 실제 계산입니다.

```python
cosine = self._np.dot(self.vector(word), self.vector(answer))
return float(self._np.clip(cosine, -1.0, 1.0) * 100.0)
```

입력과 정답에 같은 모델을 사용합니다. `clip`은 부동소수점 오차 범위를 제한하며 점수를 임의로 재분배하지 않습니다. 정답 판정은 게임 코드에서 별도로 문자열을 비교합니다.

`prepare_model.py` → `validate()`의 파일 검증 일부입니다.

```python
with path.open("rb") as stream:
    digest = hashlib.file_digest(stream, "sha256").hexdigest()
return digest == item["sha256"]
```
