## 무엇이 달라졌나요?

화면 양쪽 여백을 두 배로 늘려 달라는 요청에 따라 게임·랭킹 본문과 헤더의 좌우 여백을 조정했습니다. 이어서 요청한 대로 좁아진 본문에 맞게 글자 크기·입력 높이·간격도 줄이고, 최근 입력 단어 옆의 ‘최근’ 배지를 없앴습니다. 최근 행의 맨 위 배치·색상 강조·구분선과 나머지 기록 정렬은 유지합니다.

넓은 데스크톱에서는 본문이 지나치게 좁아지지 않도록 640px을 확보하므로, 모든 화면에서 실제 빈 공간이 정확히 두 배가 되지는 않습니다. 게임 규칙·모델·현재 로고·채팅 팝업 구조는 바꾸지 않습니다.

## 어떤 코드인가요?

변경 전 본문 너비:

```css
main { width: min(860px, calc(100% - 64px)); margin: 36px auto 106px; }
```

변경 후 일부 발췌:

```css
main {
  --side-gap: clamp(64px, calc(100% - 860px), calc((100% - 640px) / 2));
  width: calc(100% - var(--side-gap) * 2);
  margin: 36px auto 106px;
  font-size: 14px;
}

.start-button { min-width: min(210px, 100%); max-width: 100%; min-height: 50px; }
.guess-table .attempt-column { width: 56px; }

@media (max-width: 720px) {
  main { width: calc(100% - 56px); margin-top: 24px; }
}
```

기존 최대 본문 860px을 기준으로 화면의 남는 폭을 계산하고, 좌우 여백으로 나눕니다. 넓은 화면에서는 본문 640px을 보존하며, 좁은 태블릿은 최소 여백 64px에 맞춰 본문이 더 작아질 수 있습니다. 모바일에서는 별도 규칙으로 좌우 각각 28px을 적용합니다.

최근 행의 배지는 다음과 같이 변경했습니다. 아래는 `guessRow` 안의 일부 발췌입니다.

```tsx
// 변경 전
{item.is_correct ? <span className="correct-label">정답</span> : recent && <span className="recent-label">최근</span>}

// 변경 후
{item.is_correct && <span className="correct-label">정답</span>}
```

최근 행 여부를 판단하는 `recent`와 `recent-row` 클래스는 계속 사용하므로 단어·점수의 강조와 맨 위 한 행 표시가 유지됩니다. 스크린리더용 표 설명은 남깁니다.

## 영향과 남은 일

- DB·모델·게임 규칙·실제 `.env` 변경 없음. 기존 기록을 유지합니다.
- 최종 화면 파일을 실행 중인 로컬 앱 이미지에 빌드해 반영했습니다. 브라우저 새로고침으로 확인할 수 있습니다. GitHub 업로드·공개 배포는 하지 않았습니다.
- 넓은 데스크톱에서 전체 좌우 빈 공간을 정확히 두 배로 만드는 것은 본문 640px 제한 때문에 적용하지 않습니다. 예를 들어 1600px 화면에서 정확한 두 배는 본문이 120px만 남습니다.
- 실제 Windows Chrome에서 검사했습니다. 실제 모바일 기기·Mac·Safari는 미검증입니다.
