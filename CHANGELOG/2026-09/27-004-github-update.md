## 무엇을 반영하나요?

사용자의 GitHub 커밋 요청에 따라 아래 세 작업의 소스·검사·문서를 하나의 커밋으로 묶습니다. 화면 파일에 함께 적용된 변경이므로 파일을 임의로 분리하지 않습니다. 원격 `origin/main`을 조회한 결과 로컬 기준 커밋과 같아 기존 `main`을 사용합니다.

- [27-001 코드 가독성](27-001-code-formatting.md): 화면 코드 줄바꿈·들여쓰기와 CSS 설명 정리.
- [27-002 완료 화면](27-002-completion-panel.md): 정답 완료 상자·내 통계·상위 1,000개 단어 링크. 기록 복사 기능 제외.
- [27-003 친구 기록](27-003-friend-history.md): 정답 후 닉네임으로 당일 풀이 과정 열람, 서버 권한·날짜 검사, 기존 채팅 유지.

각 기능의 수정 파일·함수·핵심 코드는 위 기록을 참조합니다. 이번 커밋 정리에서는 앱 동작을 추가로 바꾸지 않았습니다.

## 확인 결과

- 이번 확인: 원격 fetch 후 `HEAD...origin/main` 차이 0/0, 커밋 후보와 제외 규칙 감사, 비밀키 형태 탐지, `git diff --check` 통과.
- 이번에 읽은 저장 검사 결과: Chrome 33개 통과·JavaScript 오류 0, 실제 모델 통합 8개 묶음 통과. 검사용 프로필·DB·설정 정리 완료.
- 앞선 기능 작업에서 실행한 결과: 백엔드 288개 통과, TypeScript·Vite Docker 빌드 통과. 코드 변경 없이 커밋하는 작업이므로 같은 검사를 반복 실행하지 않습니다. 구체적인 실행 결과는 [27-003](27-003-friend-history.md)에 있습니다.
- GitHub Actions는 push 시 기존 [check.yml](../../.github/workflows/check.yml)에 따라 별도로 실행됩니다. 로컬 검사 결과와 구분하며, 커밋 업로드는 앱의 공개 배포를 실행하지 않습니다.
