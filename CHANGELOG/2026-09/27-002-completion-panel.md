## 무엇이 달라졌나요?

한 줄짜리 정답 안내를 참고 이미지의 구조에 맞춘 React 완료 상자로 바꿨습니다. 이미지 파일을 화면에 붙이지 않고, 정답과 시도 횟수·유사어 링크·다음 문제·내 플레이 기록을 실제 데이터로 표시합니다. 현재 흰색/하늘색 디자인과 하단 랭킹·작은 채팅 구조는 유지합니다. 후속 요청에 따라 기록 복사 기능은 넣지 않습니다.

## 계산과 표시 기준

- 첫 도전 날짜는 `games.puzzle_date`의 최솟값입니다. 존재하지 않는 회차 번호를 만들지 않습니다.
- 도전·정답·미완료 횟수는 본인 게임 기록에서 계산합니다. ‘미완료’는 자정에 닫힌 도전이며 오늘 진행 중인 게임은 포함하지 않습니다. 별도 포기 버튼은 추가하지 않습니다.
- 연속 정답은 오늘부터 날짜가 하루씩 이어지는 정답 기록입니다. 접속하지 않은 날짜나 미완료 날짜가 있으면 끊깁니다.
- 누적 추측 수는 최초 시도 수의 합계입니다. 중복 단어를 다시 입력해도 증가하지 않습니다.
- 유사어는 정답을 제외한 원 코사인 점수 내림차순의 **1,000개**입니다. 동점의 공동 순위는 유지하지만 경계 동점이 있어도 목록 길이는 1,000개입니다. 기준 점수는 동일 목록의 1·10·1,000번째 점수와 같습니다.
- 통계와 유사어는 본인이 오늘 정답을 맞혔을 때만 제공합니다. 미완료 사용자에게 단어 목록이 노출되지 않도록 API에서 확인하고 자정 경계도 검증합니다.
- 상위 단어 링크는 같은 화면에서 목록을 펼칩니다. 로딩·조회 실패·재시도·닫기를 지원하며 새 날짜로 바뀌면 이전 목록은 사라집니다.

## 핵심 코드

`game.py`는 오늘 본인 게임이 완료된 경우에만 저장 기록을 집계합니다.

```python
if saved["status"] == "completed":
    stats = player_stats(conn, user["id"], day)
```

`CompletionPanel.tsx`의 `href="#related-words"` 링크를 누르면 같은 화면에 목록이 열립니다. `/api/related-words`를 요청할 때 현재 서버 날짜를 보내고, 패널을 닫거나 날짜가 바뀌면 `AbortController`로 이전 요청을 취소합니다.
