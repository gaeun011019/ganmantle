- 유형: 변경 / 수정 / 삭제

- 관련 커밋: 미기록

## 무엇이 달라졌나요?

추측표의 글자와 막대를 키우고, 커진 본문이 과도하게 강조되지 않도록 단어와 점수를 일반 굵기로 조정했습니다. 순위 막대의 채움 색은 한 가지 파랑으로 통일하고 순위 차이는 길이와 숫자로 표시합니다.

본문 여백과 모델·게임 산식·DB는 유지합니다. 최근 행 아래의 구분선과 진한 파랑 강조, 입력창과 버튼의 공통 테두리도 유지합니다. 이전 [005 변경](21-005-word-contrast.md)의 완료 기록은 수정하지 않습니다.

글자와 막대가 행 안에서 더 크게 보이도록 내부 패딩을 줄이고 표시 크기를 키웁니다. 본문 바깥 여백, 전체 화면 제목과 하단 랭킹의 글자 크기는 바꾸지 않습니다. 추측표 제목은 굵기 600을 유지하며 일반 단어·점수·최신·정답 단어와 점수는 모두 400을 사용합니다.

변경 전 일부 발췌:

```css
.guess-table { font-size: 15px; }
.rank-track { height: 15px; }
.rank-fill { background: #a2c8dc; }
.rank-top > .rank-fill { background: #1c6890; }
.rank-close > .rank-fill { background: #338db8; }
.rank-near > .rank-fill { background: #6aabc9; }
```

변경 후 핵심 값:

```css
.guess-table { min-width: 540px; font-size: 20px; }
.guess-word { font-weight: 400; }
.score { font-weight: 400; }
.rank-track { height: 28px; }
.rank-fill { background: var(--blue); }

@media (max-width: 720px) {
  .guess-table { font-size: 18px; }
  .rank-track { height: 24px; }
}
```

위 CSS는 변경한 속성만 발췌했습니다. 최신·정답 행의 별도 글자 굵기 지정을 제거해 단어와 점수의 400을 그대로 사용합니다. `WordRank`의 색 구간을 고르던 `tone` 분기와 `rank-top`·`rank-close`·`rank-near` 스타일을 제거하고 채움 길이는 기존 식을 사용합니다.

```tsx
const fill = correct ? 100 : inRange ? ((1001 - rank) / 1000) * 100 : 0;
```

- 모델·DB·게임 규칙·순위 채움 산식·정렬·본문 여백 변경 없음.
- 최신 행 구분선·강조와 입력 폼 공통 테두리 유지.
- 본문 굵기 400까지 포함한 최종 화면을 로컬 앱에 빌드해 반영했습니다. GitHub 업로드·공개 배포는 수행하지 않았습니다.
