# 2026-10-04 — 닉네임 입력창과 버튼을 한 테두리로 표시

- 기록 ID: 2026-10-04-001
- 분야: 화면 / 문서
- 유형: 변경
- 구현 상태: 완료
- 관련 커밋: 미기록

## 무엇이 달라졌나요?

닉네임 입력창도 추측 입력창처럼 입력칸과 제출 버튼을 하나의 둥근 테두리로 감싸도록 바꿨습니다. 입력하거나 키보드로 버튼을 선택하면 행 전체에 파란 포커스 테두리가 표시됩니다.

| 변경 전 | 변경 후 |
|---|---|
| 닉네임은 입력칸 자체에 테두리·포커스를 표시하고, 추측 입력에만 행 전체 테두리를 적용 | 두 입력창 모두 입력칸·버튼 전체에 같은 테두리와 포커스 표시 |
| 비활성 닉네임 버튼의 외곽이 입력칸과 따로 보임 | 버튼이 비활성이어도 전체 외곽선 유지 |

## 어디를 수정했나요?

| 파일 | 코드 위치 | 변경한 내용 |
|---|---|---|
| [styles.css](../../frontend/src/styles.css) | `.input-row`, 자식 `input`·`button`, `:focus-within`, `:focus-visible` | 기존 `.guess-form` 전용 외곽선·둥근 모서리·포커스를 공통 입력 행 규칙으로 이동 |
| [월별 목록](README.md), [전체 목록](../README.md) | 2026년 10월 및 최신 항목 | 이번 변경 기록 연결 |

두 폼은 이미 `.input-row`와 `.input-wrap`을 공유하므로 JSX 변경은 필요하지 않았습니다. `.guess-form` 클래스는 게임 입력 구분용으로 유지합니다. 닉네임 길이 검사·한국어 조합 입력·저장 동작·접근성 라벨은 그대로입니다.

## 어떤 코드인가요?

기존 `.guess-form`에만 적용되던 다음 규칙을 `.input-row`로 옮겼습니다. 일부 발췌입니다.

```css
.input-row {
  border: 1px solid #8097a8;
  border-radius: 10px;
  background: #fff;
}

.input-row:focus-within {
  border-color: #175e80;
  outline: 2px solid #76c0e5;
  outline-offset: 2px;
}
```

자식 입력·버튼의 테두리는 없애고 안쪽 모서리를 9px로 맞춥니다. 버튼에 키보드 초점이 있을 때는 안쪽 포커스 표시도 유지합니다.

## 어떻게 확인했나요?

| 확인 방법 | 결과 |
|---|---|
| `npm.cmd run build` | TypeScript 검사·Vite 빌드 통과. 최초 샌드박스 실행의 상위 경로 접근 실패 후 일반 권한으로 재실행 |
| 기존 `scripts/check_ui.mjs`, 로컬 미리보기 사용 | 17번째 검사에서 중단. 기존 검사는 `정답 단어를 맞혔습니다.`를 기대하지만 현재 `CompletionPanel.tsx`는 느낌표를 출력함. 이번 CSS 변경과 무관한 문구 불일치이며 전체 통과로 기록하지 않음 |
| 기존 검사 자료를 재사용한 일회성 닉네임 화면 검사 | 1600·390·320px에서 총 6개 검사 통과. 추측 입력과 전체 테두리·포커스 일치, 버튼 활성화와 Tab 초점, 입력·버튼 겹침 및 페이지 가로 넘침 없음 확인 |
| 스크린샷 검토 | 데스크톱 입력 초점·390px 입력 초점·320px 버튼 초점 캡처를 직접 확인. 입력칸과 버튼 전체를 감싸는 선과 둥근 모서리 정상 |
| `docker compose build app` | 새 프런트엔드를 포함한 이미지 빌드 통과. 기존 이미지는 로컬 복구 태그로 보존 |
| `docker compose up -d --no-deps --no-build --wait --wait-timeout 360 app` | 실행 중인 앱에 반영하고 `Healthy` 확인 |
| 실행 앱 HTTP 확인 | `/api/health`와 첫 화면 모두 HTTP 200. 실제 제공 CSS가 로컬 검증 빌드와 동일하고 공통 포커스 규칙을 포함함 |
| `git diff --check` | 통과 |

검사 스크립트는 Git에서 제외하는 `.cache/`, 결과와 캡처는 `test-results/nickname-ui-checks.json` 및 `test-results/nickname-*.png`에 있습니다. 실제 게임 API 대신 검사 전용 자료를 사용해 사용자 기록을 만들지 않았습니다.

## 영향과 남은 일

- DB·모델·환경변수·게임 규칙 변경 없음.
- 실행 반영: 새 이미지로 앱을 재시작하고 준비 완료를 확인했습니다. 사용하던 공유 주소에서 새로고침하면 새 CSS를 받습니다. 검사에 사용한 별도 미리보기 서버는 종료했습니다.
- 기존 전체 화면 검사의 정답 문구 기대값 불일치는 이번 범위에서 수정하지 않았습니다.
- Git 커밋·GitHub 업로드는 실행하지 않았습니다.
